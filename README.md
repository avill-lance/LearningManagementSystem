# Learning Management System

A Laravel-based Learning Management System for managing educational institutions, featuring student enrollment, course management, grading, attendance tracking, and more.

## 🚀 Features

- Student and teacher management
- Course and subject management
- Enrollment tracking
- Grade management and reporting
- Attendance tracking
- Quiz and assignment system
- Announcements and notifications
- Audit logging
- Role-based access control

## 🔧 Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd LearningManagementSystem
   ```

2. **Install PHP dependencies**
   ```bash
   composer install
   ```

3. **Install Node.js dependencies** (if using Laravel Mix/Vite)
   ```bash
   npm install
   ```

4. **Create environment file**
   ```bash
   cp .env.example .env
   ```

5. **Generate application key**
   ```bash
   php artisan key:generate
   ```

6. **Run database migrations**
   ```bash
   php artisan migrate
   ```

   This will create all necessary tables including the sessions table required for database session storage.

7. **Compile frontend assets** (required for proper Vite integration)
   ```bash
   npm run dev
   ```
   For production:
   ```bash
   npm run build
   ```
> **Note**: The Vite manifest file (`public/build/manifest.json`) is generated by the build process and is required for the application to load CSS and JavaScript assets correctly. If you encounter a "Vite manifest not found" error, run `npm run build` (for production) or keep `npm run dev` running during development.

## 🖥️ Usage

### Development Server

Start the local development server:
```bash
php artisan serve
```

The application will be available at http://localhost:8000

### Queue Worker

If using database queues, start the queue worker:
```bash
php artisan queue:work
```

### Scheduler

To enable automatic task scheduling, add this to your crontab:
```bash
* * * * * php /path/to/artisan schedule:run >> /dev/null 2>&1
```

## 🗄️ Database Configuration

This application uses SQLite by default for simplicity. The database file is located at:

```
database/database.sqlite
```

To switch to MySQL or another database:

1. Update the `.env` file:
   ```env
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=your_database_name
   DB_USERNAME=your_username
   DB_PASSWORD=your_password
   ```

2. Ensure the database exists and the user has appropriate permissions
3. Run migrations: `php artisan migrate`

## 🔐 Security

- Never commit your `.env` file to version control (it's already in `.gitignore`)
- Always use environment variables for sensitive configuration
- Keep dependencies updated
- Use HTTPS in production

## 💡 Troubleshooting

### "No such table: sessions" Error
If you encounter this error, ensure you have run:
```bash
php artisan migrate
```
This creates the sessions table required for database session storage.

### Permission Issues
Ensure the `database` directory and `database.sqlite` file are writable by the web server process:
```bash
chmod -R 755 database
chmod 664 database/database.sqlite
```

### Key Not Generated
If you see encryption errors, generate an application key:
```bash
php artisan key:generate
```
